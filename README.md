# PARTICLE ULTRA · 十万粒子交互宇宙

单文件 Canvas 2D 粒子交互页面：100,000 个粒子、10 种程序化形态、音频频谱律动、摄像头手势控制。零依赖，不用 WebGL。

## 文件

- `index.html` — 加强版：手势库多线路容灾、跟随提速、比手指数切形态、双手缩放
- `post.html` — 配套复盘文章：《当粒子学会跟随 · 交互修复复盘》

## 怎么玩

用 https 打开 `index.html`（GitHub Pages 或任意静态托管；本地双击 file:// 打开时，浏览器会禁用摄像头，手势不可用，但粒子和鼠标互动正常）。

点面板里的「✋ 摄像头手势」，允许使用摄像头，然后：

- 张开手掌 / 握拳：控制粒子群张合
- 移动手掌：粒子群跟着手走
- 伸出 1~5 根手指保持约半秒：切换形态（星云 / 星系 / 爱心 / 土星 / 莲花）
- 双手同时出镜，拉开或靠近：缩放粒子群

鼠标移动有涡流互动，点击有冲击波；麦克风开启后粒子会跟着声音的频谱跳动。
